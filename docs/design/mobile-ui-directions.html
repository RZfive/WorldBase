Navigation

Tab 栏为什么退役

Tab 栏属于内容型 App(微信、微博)——用户来「逛」。AI 助手是单一任务流:打开 → 说话 → 得到结果。DeepSeek、千问、ChatGPT、Claude、Gemini 已全部收敛到同一个范式:对话即主页,历史进抽屉,能力进「+」,模型进顶部胶囊。省下的 56px 还给对话本身。

现在的元素新位置理由
Tab「对话」→ 即主页,打开 App 就是最高频路径零跳转
历史会话列表→ 左上浮岛 · 悬浮玻璃抽屉低频,但一滑即达
Tab「应用」「绘图」→ 输入条「+」能力面板 + 抽屉固定入口能力是对话的输入,不是平级的目的地
Tab「我的」→ 抽屉底部用户行(账号 / 设置)设置是低频出口,不该占据常驻面积
模型切换(埋在设置里)→ 顶部中央玻璃胶囊,随点随换按对话选模型是常态操作,该浮在面上
深度思考 / 联网开关→ 输入条上方开关 pill按消息粒度切换,而非全局设置
Material

三层流体玻璃

iOS 26 的 Liquid Glass 关键不是"更模糊",而是透镜感:悬浮投影让玻璃浮起,顶部 1px 内高光模拟边缘折射,135° 斜向 sheen 给出曲面——三者缺一不可。按层级分三种规格,层级越高、玻璃越"厚"。

层级用途背景模糊边缘投影
L1 · 浮岛玻璃 顶栏按钮、模型胶囊、输入条、抽屉 white 52%28px × 1.8 饱和 1px white 68% + 顶部内高光 + sheen 0 10 28 / indigo 30%
L2 · 气泡玻璃 AI 气泡、流式消息 white 44%18px 1px white 58% + 顶部内高光 0 6 18 / 22%
L3 · 内容玻璃 建议 chips、工具卡、开关 pill white 38%14px 1px white 52% 0 4 14 / 18%
深色模式不是反色:三层玻璃统一改为 rgba(18,20,34,50–60%),描边与顶部内高光保留——玻璃在暗处反而更像玻璃,这是 Liquid Glass 与旧毛玻璃的分水岭。背景「晨昏渐变」在夜间整体压暗、色温转蓝紫,曦橙只留在 Orb 与发送键上。

Details

让它"活"起来的六个细节

  • 时间问候——空态问候随时间变化(上午好 / 下午好 / 晚上好),AI 有"时间感",这是人文感的最低成本来源。
  • 每日建议——三条建议 chips 每日轮换,来自日历、最近对话与使用习惯,而不是写死的功能广告。
  • 深度思考可见——思考过程折叠为玻璃 pill(「已深度思考 · 12 秒」),点开可展开推理;过程不再是一个沉默的转圈。
  • 流式光标是一道光——2.5px 渐变光标 + 光晕,1.1s 明暗;文字像被"写"出来,而不是"掉"下来。
  • 弹簧动效——浮岛入场 200ms spring;抽屉 280ms easeOutCubic;Orb 呼吸 4.5s 一个周期,思考时频率加快。
  • 内容穿过玻璃——消息列表延伸到顶栏与输入条之下滚动,玻璃把它们柔化成背景色,界面因此"深"了一层。
Themes

暖屿与苔径没有浪费

2.0 的玻璃骨架与配色解耦——主题可整体切换,晨昏是默认。方向 B、C 的精华以两种方式并入:

  • 暖屿 → 成为第二套主题——问候头、时间感文案已并入 2.0;纸墨陶土配色作为「暖屿主题」整体保留,一键切换。
  • 苔径 → 并入组件层——23px+ 大圆角、按压下沉 2pt 的触感反馈直接进入玻璃组件;绿影签名留给未来的「苔径主题」。
Implementation

Flutter 落地清单

全部改动仍集中在 apps/mobile/lib 的表现层,不动 harness 通信。建议顺序:先拆 Tab、再封玻璃组件、最后做空态与动效。

  • 拆 Tab 栏worldbase_app.dart 移除 IosTabBar + IndexedStack,home 直接挂载 ChatTab;原 LaunchpadTab / StudioTab / SettingsTab 改由抽屉路由进入。
  • 封装 GlassContainer新增 core/glass.dart:ClipRRect + BackdropFilter(blur 28, saturate 1.8) + 内高光渐变 + 悬浮阴影,三个层级参数化;替换 ios_ui.dart 中的纯色容器。
  • 顶部三浮岛IosNavBar → 菜单 / 模型胶囊 / 新会话;消息 ListView 加大上下 padding,让内容从玻璃下滚过。
  • 悬浮抽屉Scaffold.drawer + 玻璃材质,分组(今天 / 昨天 / 更早)+ 搜索 + 应用入口 + 底部用户行;四周 10px 内收,圆角 26。
  • 输入条改造IosChatInputBar → 悬浮胶囊(圆角 27、L1 玻璃);上方加「深度思考 / 联网搜索」TogglePill,状态按会话保存。
  • 空态组件新增 GreetingHeader(按小时取问候语)+ SuggestionChips(每日 3 条,可从 conversationsProvider 与日历推导)。
  • 深色模式三层玻璃直接给出暗色 token(背景 rgba(18,20,34,.5–.6),高光保留);buildIosTheme() 补 ColorScheme.dark,晨昏渐变夜间转蓝紫。

晨昏 2.0 = 方向 A 的配色 × DeepSeek/千问式导航 × iOS 26 流体玻璃。建议先用「对话」单页做样板:拆 Tab、封 GlassContainer、上浮岛与胶囊,跑顺后再铺抽屉与深色。源文件:docs/design/mobile-ui-directions.html
