# The World 用户手册

更新时间：2026-05-08

## 手册摘要

**The World** 是一个面向项目全生命周期的 AI 桌面工作台。它不是单纯的聊天窗口，而是把 **AI 对话、项目创建与运行、网页操作、源码浏览、数据库查看、进程管理、定时任务、MCP/Skill 扩展** 放进同一个 Electron 应用里，让你可以在一个界面里持续推进项目。

本项目的亮点与价值在于：

- **从“提需求”到“看结果”闭环完成**：你可以先在聊天里描述需求，再直接启动项目、查看页面、继续优化、验证运行结果。
- **项目与网页都能纳入同一工作台**：运行中的项目、常用网页、局域网访问入口都能进入 Dock 与 Launchpad，减少来回切换。
- **AI 能结合真实上下文工作**：除了聊天文本，AI 还能结合文档标签、项目上下文、Skill、MCP、Agent、群组协作和网页页面快照推进任务。
- **适合持续管理而不是一次性生成**：设置中心提供日志、数据库、进程、定时任务、配置迁移等能力，更适合长期使用和团队协作。

如果你希望把 The World 当成一个“AI 驱动的项目操作系统”，这份手册就是它的日常使用说明。

## 1. 产品定位

The World 主要由以下几部分组成：

| 模块 | 作用 |
| --- | --- |
| 聊天中控 | 与 AI 对话，创建、修改、分析项目，调用工具，审批执行 |
| 启动台 Launchpad | 管理项目和网页快捷方式，整理分组，导入导出项目包 |
| 应用运行壳 | 在主界面中打开项目或网页，并通过 Dock 快速切换 |
| 源码查看器 | 只读浏览项目文件树与源码内容 |
| 设置中心 | 配置模型服务、MCP、Skill、Agent、定时任务、日志、数据库与进程 |
| 文档工作台 | 导入 PDF/Office 文档，框选内容后以标签形式注入到提问中 |

## 2. 快速开始

## 2.1 启动应用

如果你使用已打包的桌面应用，直接启动即可。

如果你从源码运行本项目，可使用：

```bash
pnpm install
pnpm electron:dev
```

如果需要构建安装包，可使用：

```bash
pnpm electron:build
```

## 2.2 首次使用建议顺序

推荐按照下面的顺序完成首次配置：

1. 打开 `设置 -> 模型服务`，配置至少一个可用的 AI Provider。
2. 回到聊天视图，创建第一条对话，测试模型是否可正常回复。
3. 如果你要让 AI 使用外部工具，再进入 `设置 -> MCP 管理` 或 `设置 -> Skill 管理` 完成扩展接入。
4. 如果你要长期维护多个项目，可在 `启动台` 中整理项目、分组和网页快捷方式。
5. 如果你需要让 AI 参考外部文档，打开 `文档工作台` 导入 PDF、Word、Excel 或 PowerPoint 文件。

## 3. 主界面总览

## 3.1 Dock 导航

左侧 Dock 是应用的主导航，负责在不同工作模式之间切换：

- `💬 对话`：返回聊天主界面。
- `运行中的应用/网页图标`：切换到当前已打开的项目或网页。
- `🚀 启动台`：打开 Launchpad。
- `⚙️ 设置`：进入设置中心。

Dock 中的项目或网页图标会显示运行状态。对运行项点击右键可以打开上下文菜单。

## 3.2 四个核心视图

| 视图 | 说明 |
| --- | --- |
| Chat | 默认工作区，用来和 AI 对话 |
| App | 嵌入式运行项目页面或浏览网页 |
| Source | 查看项目源码 |
| Settings | 查看和修改系统配置 |

## 4. 聊天中控使用说明

## 4.1 会话结构

聊天左侧侧栏分为三类内容：

- `Agent`：与某个专属 Agent 绑定的会话。
- `群组`：多 Agent 协作会话。
- `对话`：普通自由对话记录。

你可以在侧栏中完成以下操作：

- 新建对话。
- 搜索 Agent、群组或历史对话内容。
- 切换到指定会话。
- 删除历史会话。

## 4.2 聊天头部

聊天头部会显示当前上下文，例如：

- 当前是普通对话、某个 Agent 会话，还是某个 Agent 群组会话。
- 当前模型或群组协作状态。

在头部还可以执行：

- 选择 `IM 绑定`。
- 打开 `Skills` 选择器，按需激活或清空当前会话可用 Skill。

## 4.3 输入区功能

聊天输入区除了文本输入，还包含以下控制：

| 控件 | 作用 |
| --- | --- |
| Agent 下拉 | 在新对话时选择默认 Agent |
| Provider / Model | 选择模型服务与模型 |
| 思考强度 | 低 / 中 / 高 / 最高 |
| 授权模式 | `strict` 严格授权 或 `auto` 自动执行 |
| 规划模式 | 进入或退出规划式协作 |
| 文档中心按钮 | 打开文档工作台 |
| 附件按钮 | 上传文件或图片 |
| 发送 / 停止按钮 | 发送当前请求，或停止生成 |

快捷说明：

- `Enter` 发送消息。
- `Shift + Enter` 换行。
- 运行中时发送按钮会变为停止按钮。
- 如果当前有待审批操作，输入区会显示“等待授权以继续执行”。

## 4.4 授权模式

The World 支持两种执行授权模式：

- `strict`：AI 在执行敏感操作前需要你人工确认。适合高风险项目或首次试用。
- `auto`：AI 自动执行，无需每次审批。适合熟悉工作流后的连续任务。

建议：

- 初次使用、真实生产项目或带文件修改时优先使用 `strict`。
- 连续性的低风险整理任务可以使用 `auto`。

## 4.5 规划模式

规划模式适合让 AI 先整理方案、拆解步骤、生成执行路径，再进入实做。适用于：

- 新项目规划。
- 复杂需求拆分。
- 多阶段任务安排。

## 4.6 附件与文档标签

聊天支持上传图片和普通文件。除此之外，还支持更强的文档工作台机制：

- 你可以导入 PDF、Word、Excel、PowerPoint。
- 在文档预览中高亮某段内容后，系统会自动创建一个文档标签。
- 点击标签可把它插入到聊天草稿中。
- 只有实际插入到输入框的标签，才会在发送时注入给 AI。

这意味着你可以精准控制 AI 只参考某几段文档，而不是整份文件。

## 4.7 项目标签

聊天输入支持项目上下文标签。通常在 `启动台 -> 继续优化` 或 Dock 的 `继续优化` 进入聊天时，会自动附带对应项目上下文，便于 AI 在正确项目上继续工作。

## 4.8 群组会话与 @ 提及

群组会话支持多 Agent 协作，并支持输入 `@` 触发成员提示列表。适用于：

- 指定某个 Agent 回答。
- 在群组中限定讨论范围。
- 将不同角色的 Agent 组织成协作链路。

## 5. 文档工作台

文档工作台位于聊天区底部，可独立展开与关闭。

## 5.1 支持格式

- PDF
- Word (`.docx`)
- Excel (`.xlsx`)
- PowerPoint (`.pptx`)

单个文档最大支持 `100MB`。

## 5.2 使用步骤

1. 点击聊天输入区的文档按钮。
2. 在左侧点击 `导入文档`。
3. 选择本地文档并等待导入完成。
4. 点击文档查看预览。
5. 在预览中高亮内容，系统会自动生成标签。
6. 点击标签，把它插入聊天输入框。
7. 发送消息，让 AI 仅围绕这些标签对应的片段工作。

## 5.3 文档工作台还能做什么

- 查看文档类型、文件大小和标签数量。
- 删除导入文档。
- 删除文档标签。
- 打开原始文件。

## 6. 启动台 Launchpad

Launchpad 是项目和网页的统一入口。

## 6.1 启动台中的两类条目

- `项目`：由 The World 管理的应用项目。
- `网页快捷方式`：保存到启动台的浏览器网页入口。

## 6.2 搜索与网址直开

启动台顶部支持搜索：

- 输入项目名、类型或网址进行过滤。
- 如果输入内容被识别为网址，可以直接按回车打开网页。

这意味着 Launchpad 同时也是一个轻量的“网址启动器”。

## 6.3 文件夹整理

你可以通过拖拽完成整理：

- 把项目拖到另一个项目上，生成文件夹。
- 把项目拖进已有文件夹。
- 从文件夹中移出项目。
- 新建空文件夹并重命名。
- 删除文件夹后，内部项目会回到顶层。

## 6.4 项目右键菜单

对项目卡片点击右键，可执行：

- `打开应用`
- `修改名称与图标`
- `查看源码`
- `导出应用`
- `独立窗口运行`
- `启动` / `停止`
- `继续优化`
- `移入文件夹`
- `移出文件夹`
- `删除项目`

## 6.5 网页快捷方式右键菜单

对网页卡片点击右键，可执行：

- `打开网页`
- `移入文件夹`
- `移出文件夹`
- `从启动台移除`

## 6.6 空白区域右键菜单

在启动台空白处点击右键，可执行：

- `新建文件夹`
- `导入应用`
- `刷新`

## 6.7 项目包导入与导出

The World 支持项目包导入导出，包扩展名为：

```text
.twapp
```

你可以：

- 从项目右键菜单导出应用包。
- 从启动台空白处右键导入应用包。
- 将 `.twapp` 文件直接拖到启动台进行导入。

这适合在设备之间迁移项目，或与团队成员共享项目模板。

## 7. 项目与网页运行壳

## 7.1 打开项目

项目可通过三种方式进入运行态：

1. 在 Launchpad 中点击项目。
2. 在 Launchpad 右键选择 `打开应用`。
3. 在 Dock 中点击已运行项目图标。

如果项目尚未运行，系统会先自动启动，再在主界面中打开。

## 7.2 项目的两种打开方式

| 方式 | 说明 |
| --- | --- |
| 嵌入式打开 | 在主窗口中展示项目页面 |
| 独立窗口运行 | 单独打开项目窗口，适合多窗口使用 |

如果项目已经在独立窗口中打开，再次尝试打开时系统会优先聚焦已有窗口。

## 7.3 打开网页

网页有两种常见打开方式：

- 在启动台搜索框输入网址并回车。
- 在聊天中点击 AI 输出的网页链接，让其在应用内浏览器中打开。

打开后网页会进入 Dock，作为一个可切换的运行项存在。

## 7.4 网页与项目的区别

需要注意：

- 项目页面以嵌入式页面方式运行。
- 网页则使用内嵌浏览器组件运行，可追踪标题、图标与当前 URL。
- **页面自动化能力目前主要面向“应用内打开的网页”**，而不是普通项目 iframe 页面。

## 7.5 浏览网页时的浮动任务气泡

当你处于网页视图并使用聊天协作时，界面会出现浮动气泡，用来提示：

- 当前是否还在执行中。
- 有多少待授权操作。
- 有多少待办事项。

点击气泡后，聊天会以覆盖层形式展开，便于你在不离开当前网页的情况下继续协作。

## 7.6 网页自动化能力

当网页在应用内打开后，AI 可结合页面快照执行基础自动化操作，包括：

- 读取当前页面文本和交互元素摘要。
- 点击页面元素。
- 向输入框填入文本。
- 页面滚动。
- 等待指定时间。

适合场景：

- 表单填写。
- 页面检查。
- 简单操作回放。
- 把网页当作 AI 的实时工作界面。

## 8. Dock 上下文菜单

## 8.1 运行中项目右键菜单

在 Dock 中对运行中的项目点击右键，可执行：

- `独立窗口打开`
- `打开源码`
- `继续优化`
- `局域网访问`
- `停止`

## 8.2 运行中网页右键菜单

在 Dock 中对运行中的网页点击右键，可执行：

- `添加到启动台` 或 `更新启动台条目`
- `从启动台移除`
- `关闭网页`

这意味着你可以先临时打开网页，再决定是否把它固定为长期入口。

## 8.3 局域网访问

对于运行中的项目，Dock 提供 `局域网访问` 功能：

- 自动生成局域网可访问链接。
- 自动生成二维码。
- 支持一键复制访问地址。

适合在手机、平板或同一局域网内的其他设备上快速预览项目。

## 9. 源码查看器

源码查看器是一个只读浏览器，用于快速审查项目结构和文件内容。

你可以：

- 查看项目文件树。
- 展开和折叠目录。
- 点击文件查看源码。
- 查看行号。
- 获得基础语法高亮。

适用场景：

- 快速理解项目结构。
- 验证 AI 修改了哪些文件。
- 无需进入外部 IDE 就能浏览代码。

注意：当前源码查看器侧重 **只读查看**，不是完整代码编辑器。

## 10. 设置中心

设置中心分为九个面板。

## 10.1 通用设置

通用设置包含三块内容：

- `显示设置`：浅色、深色、跟随系统。
- `执行通知`：任务结束后是否发送系统通知。
- `配置迁移`：导出与导入加密配置包。

配置迁移适合多设备同步设置，但不会迁移聊天记录、项目源码和已导入文档。

## 10.2 模型服务

模型服务面板用于管理 AI Provider。

你可以：

- 新增、编辑、删除 Provider。
- 配置 `Base URL`、`API Key`。
- 为每个 Provider 维护多个模型。
- 配置模型上下文窗口大小。
- 配置模型价格。
- 设置启用状态和默认 Provider。
- 设置预算上限。

这是首次使用时最先需要配置的面板。

## 10.3 MCP 管理

MCP 面板用于接入外部 MCP Server。

支持：

- `stdio` 方式接入。
- `HTTP / SSE` 方式接入。
- 配置命令、参数、工作目录、环境变量、请求头和超时。
- 查看连接状态。
- 查看每个 MCP Server 提供的 `tools`、`resources`、`prompts` 数量。
- 刷新、断开、编辑、删除服务器。

如果你希望让 AI 接入额外工具、知识源或提示模板，应从这里开始。

## 10.4 Skill 管理

Skill 面板用于导入和管理 Skill 文件。

支持导入格式：

- `.md`
- `.txt`
- `.zip`

导入后你可以：

- 查看 Skill 名称、描述和创建时间。
- 展开查看 Skill 内容。
- 删除不再使用的 Skill。
- 在聊天顶部按需激活当前会话要启用的 Skills。

## 10.5 Agent 工作台

Agent 工作台包含四个分页：

- `Agent`
- `群组`
- `IM 绑定`
- `记忆`

### Agent

你可以创建和维护自定义 Agent，包括：

- 名称、图标、描述。
- 系统提示词。
- 默认 Provider 与模型。
- 推理强度。
- 绑定 Skill。
- 允许工具和禁止工具列表。
- 记忆作用域。
- 记忆写入策略。
- 自动回复策略。

### 群组

你可以定义多 Agent 协作群组，包括：

- 协调 Agent。
- 成员 Agent。
- 最大轮数。
- 最大并行 worker 数量。
- 共享记忆作用域。
- 可见性策略。

### IM 绑定

用于把外部频道、线程、会话、群组与 The World 的内部对话绑定起来，便于后续做自动回复与跨通道协作。

### 记忆

记忆分页支持：

- 按关键字搜索记忆。
- 按 scope 类型与 scope id 查询。
- 查看记忆标题、摘要与作用域。
- 置顶记忆。
- 删除记忆。

## 10.6 定时任务

定时任务面板用于创建周期性或指定时间执行的 AI 任务。

支持三种调度方式：

- 单次执行。
- 按分钟间隔重复执行。
- 指定多个日期执行。

每个任务可配置：

- 任务标题。
- 执行提示词。
- 启用状态。
- 关联 Skill。
- 关联 MCP Server。
- 重试次数与重试间隔。

你还可以查看历史执行报告。

## 10.7 日志中心

日志中心用于回放 AI 对话与执行细节。

支持：

- 打开或关闭新的 AI 日志记录。
- 查看日志会话列表。
- 查看每条会话的状态、会话次数和错误数量。
- 查看上传给 AI 的消息。
- 查看模型请求与响应。
- 查看工具调用记录。
- 查看错误信息。
- 查看最终回复。
- 删除单条日志记录。

这对排查模型行为、执行错误和成本异常很有帮助。

## 10.8 数据设置

数据设置本质上是一个数据库浏览器。

你可以：

- 查看所有项目数据库总览。
- 搜索项目或表名。
- 查看数据库类型与路径。
- 查看表结构和主键。
- 按页浏览表数据。

注意：当前这个面板偏向 **查看与分页浏览**，不是通用数据编辑器。

## 10.9 进程管理

进程管理面板用于查看系统资源和项目进程状态。

它可以展示：

- CPU 使用率。
- 系统内存使用率。
- GPU 状态。
- 运行中进程数量。
- 总进程数量。
- 项目总内存占用。
- 遗留进程数量。

对于每个受管项目进程，你还可以：

- 重启。
- 停止。
- 强制终止。

对于遗留进程，也可以执行清理操作。

## 11. 常见任务操作路径

## 11.1 创建一个新项目

1. 进入 `对话`。
2. 配置 Provider / Model。
3. 输入你的需求，例如“创建一个记账应用”或“生成一个 React Todo 应用”。
4. 若使用 `strict` 模式，审批必要操作。
5. 等待 AI 创建完成并启动项目。
6. 在 Dock 中切换到运行中的项目查看结果。

## 11.2 继续优化现有项目

有两种常见入口：

- `启动台 -> 项目右键 -> 继续优化`
- `Dock -> 运行中项目右键 -> 继续优化`

进入后，聊天会自动带入项目上下文。

## 11.3 查看项目源码

可从以下任一入口进入：

- `启动台 -> 右键 -> 查看源码`
- `Dock -> 右键 -> 打开源码`

## 11.4 将常用网页固定到启动台

1. 先在应用内打开网页。
2. 在 Dock 中右键该网页。
3. 选择 `添加到启动台`。

后续即可在 Launchpad 中直接打开它。

## 11.5 用文档辅助 AI 工作

1. 打开 `文档工作台`。
2. 导入文档。
3. 高亮关键片段生成标签。
4. 将标签插入输入框。
5. 发送请求，让 AI 围绕这些片段回答或执行。

## 11.6 用局域网在手机上预览项目

1. 保证项目已运行。
2. 在 Dock 中右键项目。
3. 选择 `局域网访问`。
4. 扫描二维码或复制链接到手机浏览器。

## 11.7 导出项目并在另一台设备导入

1. 在启动台对项目右键，选择 `导出应用`。
2. 获得 `.twapp` 文件。
3. 在另一台设备打开 Launchpad。
4. 右键空白处选择 `导入应用`，或直接拖入 `.twapp` 文件。

## 11.8 建立自己的 Agent 工作流

1. 进入 `设置 -> Agent 工作台 -> Agent`。
2. 新建 Agent。
3. 配置系统提示词、Provider、模型、Skill 和工具范围。
4. 保存后，在新对话中选择该 Agent。

## 11.9 把 MCP 能力接入给 AI

1. 进入 `设置 -> MCP 管理`。
2. 新增 MCP Server。
3. 选择 `stdio` 或 `HTTP / SSE`。
4. 填写命令或 URL 与对应参数。
5. 保存后刷新状态。
6. 连接成功后，Agent 即可发现其 tools / resources / prompts。

## 11.10 创建自动化定时任务

1. 进入 `设置 -> 定时任务`。
2. 新建任务。
3. 填写任务提示词。
4. 设置执行时间、重试策略，并按需附加 Skill 或 MCP Server。
5. 保存并观察后续执行报告。

## 12. 数据迁移与保存范围

## 12.1 配置导出会包含什么

配置迁移功能会包含以下内容：

- 模型服务配置。
- 模型定价和预算相关设置。
- 主题偏好。
- 任务完成通知偏好。
- 启动台布局。
- 网页快捷方式。
- 部分项目打开方式相关偏好。

## 12.2 配置导出不会包含什么

以下内容不会通过通用配置包迁移：

- 聊天记录。
- 项目源码。
- 文档工作台中已导入的文件。

如果你要迁移项目本身，应使用 `.twapp` 项目包；如果你要迁移设置，应使用加密配置导入导出。

## 13. 使用建议与注意事项

1. 首次使用时务必先配置一个可用的 AI Provider，否则聊天无法进入有效工作状态。
2. 在真实项目上操作时，优先使用 `strict` 授权模式，先建立信任再切换到 `auto`。
3. 页面自动化当前更适合“应用内网页”，不要默认它能无差别控制所有项目页面。
4. 源码查看器适合审阅，不适合替代完整 IDE。
5. 数据设置面板更偏向查看，不建议把它当成数据库编辑器。
6. 定时任务要稳定运行，通常需要保持 The World 应用处于运行状态。
7. 大型文档建议先用标签限定范围，再交给 AI 处理，效果会比整份投喂更稳定。
8. 经常访问的网页建议先在应用内打开，再保存到 Launchpad，方便后续与 AI 联动。

## 14. 手册结语

The World 的最佳使用方式，不是把它当成“一个会回答问题的聊天框”，而是把它当成一个持续工作的 AI 桌面中台：

- 聊天负责提出目标与接收反馈。
- 启动台负责组织项目与网页入口。
- 运行壳负责快速验证结果。
- 设置中心负责给 AI 装上长期可用的能力。

当你把这几个模块连起来使用时，The World 的价值才会真正显现出来。
